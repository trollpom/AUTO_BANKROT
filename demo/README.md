# Воспроизводимая изолированная демонстрация

Из корня `car_lot_pilot`, после установки `requirements.txt`:

```bash
python demo/run_demo.py
```

Открыть http://127.0.0.1:8781/ . Пароль **только одноразового локального стенда**: `demo-local-only`. Это не пароль рабочего приложения. Скрипт копирует только `app/` в новую временную папку, создаёт шесть вымышленных лотов и одну тестовую таблицу. Это **не фотография автомобиля**; по ней нельзя оценить его состояние. VIN, контактов, реальных писем и найденных объявлений в фикстуре нет. После штатной остановки база и изображение удаляются.

Все почтовые задачи и сбор торгов выключены; рабочие `.env`, база и вложения не копируются. Без явного `--live-ai` ключ пуст, LLM не вызывается. Интерфейс и интеграция используются из существующего приложения.

## Настоящий запрос DeepSeek — один контролируемый запуск

Сначала в собственном checkout безопасно настройте ключ:

```bash
python scripts/configure_deepseek.py
python scripts/configure_deepseek.py --check
python demo/run_demo.py --live-ai
```

Ключ вводится скрыто, хранится в игнорируемом `.env` и не попадает в браузер. Не передавайте его в чат или аргументах команды. Демосервер читает только ключ из этой настройки, не переносит почтовые реквизиты. При отсутствии ключа запуск с `--live-ai` прекращается до создания сервера.

Лимиты: один анализ в сутки в пределах текущей временной базы, одно фото, до 1500 выходных токенов, максимум по одному поисковому запросу и странице. Это технические ограничения, а не денежный лимит аккаунта; дополнительно установите бюджет в кабинете провайдера. Повторный запуск создаёт новую базу и сбрасывает локальный счётчик, поэтому не перезапускайте стенд ради обхода лимита.

### Сценарий на 60–90 секунд

1. Открыть синтетическую Toyota Camry. Показать описание и тестовую таблицу.
2. Войти тестовым паролем; открыть «Анализ лота с DeepSeek».
3. Раскрыть фото, выбрать таблицу. Она принадлежит тестовому лоту, но не показывает автомобиль. Задать вопрос: «Укажи, что можно и нельзя заключить из этих синтетических входных данных; не придумывай техническое состояние».
4. **Снять «Искать аналоги через DeepSeek Search/Fetch»**, чтобы ограничиться одним запросом без интернет-поиска. Подтвердить принадлежность тестового изображения и согласие на его передачу. Реальные документы не выбирать.
5. Нажать «Запустить анализ» один раз. Дождаться конечного статуса. Показать наблюдения, источники свидетельств, неизвестные данные и предупреждения. Технический диагноз по таблице недопустим.
6. Без допустимых аналогов и расходов экономика остаётся неопределённой. Для отдельного офлайн-расчёта можно вручную ввести три разных синтетических аналога, явно помечая их учебными, и заполнить все расходы. Не называть их найденными рыночными объявлениями.

## Подтверждённые проверки

- 25 офлайн-тестов существующего адаптера, валидации, экономики, лимитов и API; ответы провайдера в тестах подставные.
- Пустой ключ + `--live-ai`: понятная ошибка до запуска сервера.
- Реальный браузер: каталог из шести синтетических лотов, исправленные счётчики марок, открытие карточки и тестового изображения.
- Для рабочего режима почтовые интеграции сохранены; демонстрация их не включает.
