# AUTO_BANKROT — прототип агрегатора автомобильных торгов

Локальный инструмент для сбора и структурирования сведений о лотах: описание имущества, цена, регион, VIN, источник и фотографии. Помогает свести разрозненные данные в карточку для дальнейшей ручной оценки.

**Статус:** исследовательский прототип, исходный код закрыт. Наличие парсеров не подтверждает стабильную загрузку всех источников. Встроенной LLM-интеграции в текущем коде нет; проект нельзя представлять готовым ИИ-агентом или сервисом с проверенной оценкой рыночной стоимости.

Автор — [Евгений Смирнов](https://github.com/trollpom). Прикладной проект разработки с помощью ИИ и AI coding tools.

## Реализовано в коде

- Парсеры сообщений ЕФРСБ и каталога автомобильных торгов, включая офлайн-разбор сохранённых HTML.
- Извлечение VIN, цены, региона и других полей; SQLite-хранилище и история цен.
- Веб-каталог с фильтрами, карточками и фотографиями.
- Поиск изображений, загрузка, проверка и создание превью. Принадлежность найденного фото конкретному лоту проверяется вручную.
- Модули SMTP/IMAP для запросов дополнительной информации и разбора ответов.
- Локальные административные операции и журнал событий.

Доступность сайтов и корректность данных требуют живых проверок. Гарантии полноты, выгодности покупки и юридической чистоты автомобиля не заявляются.

## Технологии

`Python 3.10+` · `FastAPI` · `SQLite` · `Requests` · `Playwright` · `Pillow` · `PyMuPDF` · `JavaScript`

## Локальный запуск

```bash
git clone https://github.com/trollpom/AUTO_BANKROT.git
cd AUTO_BANKROT
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в локальный `.env`. Для изолированной демонстрации задайте:

```dotenv
EFRSB_HOST=127.0.0.1
ADMIN_PASSWORD=
EMAIL_AUTO_SEND=0
EMAIL_AUTO_CHECK=0
TORGI_AUTO_SCRAPE=0
EMAIL2_ENABLED=0
```

Оставьте почтовые реквизиты пустыми. Пустой `ADMIN_PASSWORD` запрещает административный вход; для его проверки задайте собственную длинную случайную строку в `.env`. Общего предустановленного пароля больше нет.

```bash
python scripts/serve.py
```

Интерфейс: http://127.0.0.1:8000/ · API: http://127.0.0.1:8000/api/docs . Пустая база — ожидаемое состояние чистого запуска.

## Проверка без обращения к сайтам

```bash
python -m compileall -q app scripts
python scripts/run_scraper.py --offline data/offline
```

Для второй команды заранее подготовьте собственные обезличенные HTML-файлы сообщений. Проверьте карточку, извлечённые поля и ссылку на источник. Это проверка офлайн-разбора, а не доказательство работоспособности живого сбора. Полноценного автоматического набора тестов пока нет.

## Ограничения и безопасность

Сайты меняют вёрстку и ограничивают доступ. При ограничении остановите сбор и используйте разрешённый источник, API либо офлайн-файлы. Проект не гарантирует прохождение капч. Браузер Playwright нужен только для отдельной проверки разрешённого живого источника.

Автоотправка писем выключена по умолчанию. Не включайте её в демо и не запускайте `email_followup.py` без проверки адресатов и содержания. Почтовые сообщения, данные должников, cookie браузера, снапшоты и вложения не включаются в публичное портфолио. `data/` содержит локальные данные, а не готовую обезличенную демобазу.

Приложение рассчитано на localhost. Для публикации нужны отдельные изменения доступа, CORS и выдачи файлов: текущий `/data` монтирует каталог локальных данных. Исходный репозиторий остаётся приватным.
